# Example: A Tuned Morning Briefing

What a morning briefing looks like after a few weeks of tuning for one real user (a technical enablement lead who reads on a watch). Use it as a quality bar. Don't copy the specifics.

## What makes it good

- **Line one is the action.** "Reply to [name] on the hosting decision before your 10:00. Draft below." Not "Good morning."
- **Meeting count is committed only.** "5 committed + 2 maybe."
- **Unanswered invites get a call.** "Arch Review 1pm: decline, it collides with your 12:30 session where you have a slot."
- **Drafts instead of nags.** After an item is flagged twice, the briefing pastes a ready-to-send message. In practice this closed a 3-day-old ping within 5 minutes of the briefing landing.
- **Notes-derived numbers get checked.** If a meeting note quotes a stat, the briefing checks it against the project memory before repeating it.
- **Sections disappear when empty.** No "Slack: nothing notable."

## Shape

```
[Action needed today, with draft if it's a reply]
[Top 2 things to know, one line each]
-- below the fold --
Calendar: only prep-needed, conflicts, or unusual
Email: direct asks, one line each
Slack: mentions and high-signal threads only
Notes: action items assigned to the user from yesterday's meetings
Nudge: 1 or 2 sentences on what to tackle first
```
